## [1.0.9] - 2026-07-18

### Mobile navigation and portrait fixes

- Fixed the mobile menu overlay being constrained by the sticky header's backdrop-filter containing block.
- Made the open menu cover the full mobile viewport with explicit stacking, `100dvh` sizing, safe scrolling and overscroll containment.
- Centralized menu state handling and added Escape-key closing with focus returned to the menu button.
- Centered the hero portrait at mobile widths instead of retaining the tablet `justify-self: end` alignment.
- Added responsive image height handling so the square portrait no longer stretches vertically when its width is constrained.
- Verified at a 360 x 740 viewport using Chromium DevTools measurements: full-height menu, no horizontal overflow, working close state and a centered square portrait.
