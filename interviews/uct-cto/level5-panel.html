📝 Competency Assessment Prep

The invite mentions a competency skills assessment as part of the interview. Details will follow, but here's how to prepare for common formats.

Possible Formats

  • Written technical test: Likely Python/SQL coding tasks, database design questions, or data analysis scenarios. Review: basic Python scripts, SQL queries (SELECT, JOIN, WHERE, GROUP BY), database normalization, pandas operations.
  • Practical demonstration: Setting up a development environment, debugging code, creating a simple web page, or setting up a database connection. Review: Django project structure, PostgreSQL cli commands, Linux shell basics.
  • Case study / presentation: Given a scenario (e.g., "design a data pipeline for a research project"), present your approach. Review: system design principles, architecture diagrams, requirements analysis.
  • Psychometric / behavioural assessment: UCT competency framework-aligned questionnaire. Be consistent with your interview answers.
