Suggested Answer: "Security is layered — there's no single solution. For compliance, I work within ICTS's frameworks — they set the university-wide policies, and I ensure our departmental systems adhere to them. With SEAT, I maintained client verification and authorisation protocols through LDAP, which integrates seamlessly with UCT's identity management.

I also hold a Microsoft Security and Authentication certificate, which covers modern security patterns including JWT tokens, OAuth, and secure API design. At ComputeMore, I implemented JWT 256-bit token authentication and clean architecture patterns for API security."
