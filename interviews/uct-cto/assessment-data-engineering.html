Data Engineering & Infrastructure

The practical assessment will be very heavy on data engineering within WSL. This section is split into 4 focused modules. Work through each one — Docker first, then WSL CLI, then web servers (Python and .NET/Nginx).

Strategy

Start with WSL & Linux CLI (highest predicted weight), then Docker (containerised databases), then Python Web Servers (Django/Flask deployment), and finish with ASP.NET/Nginx/Apache (reverse proxy architecture).

Module 1
Docker & Containers
PostGIS, TimescaleDB, Kafka. Python data pipelines, MPI narrative, Pandas processing, Kaggle datasets. Timed 60-min exercise.
Module 2
WSL & Linux CLI
awk, sed, grep, cat, pipes. Process management, cron jobs. Django from the terminal. Bash data pipelines, networking & debugging. Timed 45-min exercise.
Module 3
Python Web Servers
Django scaffolding, DRF, settings.py patterns. Flask microservices. Gunicorn + systemd. WSGI vs ASGI. Database pooling. Timed 40-min exercise.
Module 4
ASP.NET, Nginx & Apache
Nginx reverse proxy, load balancing, TLS/Certbot. Apache mod_proxy. ASP.NET Core Minimal API, Kestrel, systemd services. Timed 45-min exercise.
